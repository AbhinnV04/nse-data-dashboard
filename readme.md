# NSE Scraper (Deprecated)

This project was originally built to scrape data from the National Stock Exchange (NSE) using an exploit that allowed bypassing their API restrictions. It worked successfully for a period of time, providing real-time access to market data without official API access.

However, the exploit has since been patched by NSE, and the method used to retrieve data no longer functions. As a result, the project is currently non-functional and incomplete.

> ⚠️ **Status:** Deprecated / Incomplete  
> **Reason:** NSE patched the exploit that was used to access data.

If a new workaround or public API becomes available in the future, development may resume.

This repo Shall never see the light of day again.
RIP in pieces!
